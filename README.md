# Calcular_Areas
Aplicación web de una sola página que calcula el área de un triángulo, un rectángulo y un cuadrado, usando el hook `useState` de React.

## Descripción

El usuario selecciona una figura desde un menú desplegable, ingresa las medidas correspondientes (base y altura, o lado en el caso del cuadrado) y al presionar "Calcular" se muestra el área calculada. Cuando la figura seleccionada es cuadrado, el segundo campo se deshabilita automáticamente porque solo se necesita una medida. También cuenta con un botón "Limpiar" que reinicia el formulario para hacer una nueva operación.



## Archivos del proyecto

- `index.html` — estructura principal y carga de React, Babel y estilos
- `figuras.jsx` — componente `Figuras` con la lógica de los hooks y el cálculo de áreas
- `styles.css` — estilos de la interfaz
